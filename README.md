# FEASFRONT

Do not browse landing sites. Solve for the ones that survive the vehicle.

Polar lighting becomes a constraint inside this solver. It is not the app.

**Status:** Private. Independent. Not a 2026 Space Apps submission.

## One sentence
Given a lander envelope and a science list, print the set of sites that do not kill the mission — and the empty set when the ask is impossible.

## Name check
"Site Inverse" is retired. Inversion Space is a live Los Angeles aerospace company. FEASFRONT = feasibility frontier.
