# FEASFRONT

Polar lighting is a constraint inside the solver. It is not the app.

**Owner:** Digital Currensy Inc.
**Status:** Private. Independent tool. Not a NASA Space Apps 2026 submission.
**License of our code:** Apache-2.0

Given a lander envelope and a science list, print the set of sites that do not kill the mission — and the empty set when the ask is impossible.

W0–W4 frozen. Lunar south polar −90/−80. Hours declared, not SPICE. Empty set is a letter. Faustini off the front. Vehicle-class one-pager $8k–$25k.
