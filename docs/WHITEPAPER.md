# FEASFRONT whitepaper

## The job
Program offices pick a ridge, then discover night, slope, or Earth-outage after money is spent. The honest object is a frontier: science value vs survival, with every point a feasible site or a stated infeasible ask.

## Method
Constraints, not a globe:
- Local Sun hours from terrain horizon (subroutine, written here or called as data)
- Earth / relay visibility
- Slope and PSR setback
- Night energy if arrays and batteries are given
- Science score from a declared target list

Solve: maximize science subject to survival inequalities. Output Pareto points. If no point exists, say so.

## Output
A table of sites with pass/fail per constraint and one frontier plot. No 6-DOF landing sim in v1.
